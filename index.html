The equations & model assumptions

Part I · Rolling energy
Mg d sin θ = ½Mv² + ½(bMR²)(v/R)²
v = √[2gd sin θ / (1 + b)]

Part II · Downward launch
y(t) = H − v sin θ · t − ½gt²
x(t) = v cos θ · t
H = xf tan θ + gxf² / (2v² cos² θ)

Combined · Required release
d = (1 + b)xf² / [4 sin θ cos² θ (H − xf tan θ)]
For a nonzero target: 0 < xf < H cot θ.

Optional rolling resistance: a = g sin θ / (1 + b) − aloss, and v² = 2ad. Here aloss is a constant effective deceleration along the track opposing downhill rolling (m/s²), not a friction coefficient. It approximates rolling losses, not static friction or slipping. If a ≤ 0, the ball released from rest does not roll down to the launch point; no flight is predicted. For a > 0, the required release is d = gxf² / [4a cos² θ (H − xf tan θ)]. Resistance affects the ramp only; flight still neglects air resistance. Default off reproduces the pre-lab equations.

Ideal model from the pre-lab: release from rest, rolling without slipping, I = bMR², a straight ramp and a level floor. No rolling losses or air resistance. The same θ describes the ramp and downward launch. Mass and radius cancel; g also cancels in the range–release relationship. Speed and time use g = 9.81 m/s². For a ball on rails, the effective rolling radius can differ from the ball radius.

The approximately 1.2 m (~4 ft) shading is a release-distance limit, not a universal range limit. Practice and front-room predictions use the selected angle and launch height; adjust these to match each actual apparatus. Predictions beyond the practice region are not measurements. No front-room track length has been assumed.
